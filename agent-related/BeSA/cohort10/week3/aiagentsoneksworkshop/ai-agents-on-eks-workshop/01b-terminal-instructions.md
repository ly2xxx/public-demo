# Terminal instructions

Source: https://catalog.workshops.aws/ai-agents-on-eks/en-US/10-introduction/200-terminal-instructions

## Opening the web IDE terminal

From the top left corner of the page, click on the workshop title to access the Event Dashboard. Scroll down to the Event Outputs table and locate the `IdeUrl` field. Copy this URL and open it in a new browser tab.

The URL signs you in automatically — no password to enter. After the Code Editor IDE loads, you'll see the terminal where you can run commands for the labs.

## Pasting commands in the terminal

**For Firefox users:**
- Windows/Linux: Press `Ctrl+Shift+V`
- macOS: Press `Command+Shift+V`

**For Google Chrome users:**
- You may see an alert requesting permission to access clipboard content. You must grant this access to paste commands.

## Accessing the AWS Console

Return to your Event Dashboard and locate the **AWS Console** link in the left navigation column. Click this link to open your temporary AWS account in a new browser tab.

> **Note:** Please ensure you logged out of other AWS accounts in the browser tab before opening this temporary AWS account.

You are now ready to proceed to the next section of the lab.

# Start with AWS Event

Source: https://catalog.workshops.aws/ai-agents-on-eks/en-US/10-introduction/100-start-with-event

## Running the Workshop at an AWS Event

For this workshop, you will be provided with a pre-configured AWS account through Workshop Studio. This account comes with all the necessary infrastructure and IAM policies required to complete the workshop activities. Follow these steps to access your assigned AWS account.

## Accessing Your AWS Console

1. Open Chrome or Firefox and navigate to the Workshop Studio link provided by your Event host (Open Event Dashboard).
2. On the login page, select **Email One-Time Password (OTP)**.
3. Enter your email address and the 9-digit event access code provided to you.
4. After successful login, you will be directed to the **Review and Join** page. Review the terms and conditions carefully, then click **Join event**.

Congratulations! You now have access to your AWS account for the workshop. Proceed to the Terminal instructions section to continue with the workshop.

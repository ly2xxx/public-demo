# Introduction

Source: https://catalog.workshops.aws/ai-agents-on-eks/en-US/10-introduction

In this workshop, you'll build a customer service agent for a fictional online store, deploy it on Amazon EKS, and evolve it across two infrastructure strategies: one fully self-managed, one integrating with AWS managed services. By the end, you'll have a multi-agent system with observability, memory, tool access, and sandboxed execution, all running on Amazon EKS.
